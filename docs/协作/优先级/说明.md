# 优先级线的文件不在这里

优先级线在它自己的 worktree 里自成一套，路径：

```text
D:\code\MC-priority\docs\协作\
├── 说明.md      协议（优先级线版）
├── 给CC.md      任务书
├── CC反馈.md    反馈
└── 历史\
```

**建造线的 CC 不要读写那边，也不要 cd 过去。**

为什么分开：每条线的 CC 只读自己 worktree 里的文件，
开场白对两条线都是同一句 `读 docs/协作/说明.md 并按它执行`，
不需要谁跨目录去够另一个文件夹。

开发（Cowork 侧）两个文件夹都有授权，由它统筹两条线。
