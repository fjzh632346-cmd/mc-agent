## 白话摘要

第一件事，接主干。总账本已经推进到建造线的合并轮，我把它合进来（干净快进、无冲突），全量五十一组、七十三项全过。

第二件事，把死结的病根查实了，有两层。第一层：图纸编译成施工顺序时，系统**完全不知道**「原木这类方块必须点在同一个方向的邻居的面上才放得出正确朝向」——门楼一百九十九根梁柱，在编译出来的依赖表里一根都没登记依赖；排序又只按「从低到高、由近及远」走，横梁和悬空柱经常被排在它唯一能依靠的邻居前面。第二层是我修完第一层后才暴露的：下游有一道「依赖排序」，遇到梯子这类挂在原木上的东西，会把它依赖的那节原木**硬提前**到梯子的位置，把刚排好的顺序又打乱。至于建造线问的「已有的临时参照机制为什么没救回来」：那套机制只对另一种报错触发，对这种报错从来不触发；而真正会尝试的那条「立根临时柱子」的路径，失败原因**不写日志**，所以真机上它究竟卡在哪一步，现在的证据不足以定论（技术细节里如实标了 UNKNOWN，并写了下轮补一行日志的建议）。

第三件事，修法。在编译顺序那一层加了一道「压后」：这类方块必须等它的同向参照物排好之后才轮到它，一串梁柱会像多米诺一样依次接上；图纸里本来就悬空、找不到任何参照的那几根（门楼有十根），统一**推迟到整个序列的末尾**并写一条日志，让她先把别的全盖完，而不是在半路把整个任务卡死。依赖排序改成只推迟依赖者、不再提前依赖项。拿门楼真图纸离线回放：改前六十八处错序，改后**零**；本地小屋屋脊那九根原木也不再错序、整条推迟；已完工的别墅序列逐字节不变（它一根这类方块都没有）。配了十组测试。

#### 2.2 根因（全部已证实，读码 + 探针）

1. **序列规划对轴向约束零感知**（第一层）：
   - `systems/blueprint-compatibility-adapter.js` `inferDependencies()` 只给侧挂块（梯子/壁挂牌/壁挂旗/壁挂火把/绊线钩）、门上半、床头建依赖；轴向块 **0 依赖**（探针：199 根里 0 根）
   - `utils/site-planner.js` `planBuildOrder()` 外墙序列先按「y 升序 → 离原点距离 → x → z」排，再过 `supportAwareSortPlaceSteps()`——其 `hasPlacementReference()` 对**任意**上下左右邻居都算支撑，不看轴。于是 y=72 梁层里一根 axis=x 的横梁，只要下面/侧面有任何方块就被判「有支撑」，按距离排在它唯一的同轴邻居前面
2. **编译器依赖排序把依赖项提前**（第二层，修完第一层后残留 1 处才暴露）：`systems/construction-compiler.js` `orderStepsByDependencies()` 是 DFS：访问到梯子时把它依赖的那节原木**提前到梯子所在槽位**。实证：`602,78,-16` 梯子依赖 `602,78,-17` 原木 → 原木被拽到 #1350，而它自己的参照（`602,73,-17` 砖 #1506、`602,74..77,-17` 下段柱）都在后面
3. **既有「计划参照修复」为何没救**：`isPlacementSupportFailure()`（`building-system.js:5949`）只认 `no_support_block` / `place_failed:unstable_air` / `temporary_reference_*` / `stair_temporary_reference_*`，**不含 `stateful_axis_no_*`** → `BUILD_PLANNED_REFERENCE_REPAIR_TRIGGER` 对轴向块从不触发（证据包 §4 亦证实 5 次触发全是 unstable_air）；即便触发，`findPlannedReferenceSteps()` 也是轴无关的（下→侧→上优先级），会去修一个不在所需轴上的邻居
4. **死循环成因**：`isRetryableBuildError()` 的正则不含 `stateful_axis` → 该步直接 `TERMINAL_FAILED` → 任务失败 → 保姆脚本重发 → 续建对账后同一步又是第一步 → 再失败（证据包 §3.1：`605,72,-4` 连败 3 次、`602,72,-3` 连败 5 次）。任何层面都没有「推迟」这一档
5. **临时参照路径**（`actions/build.js:3408-3610`）：axis=y 只允许「正下方」一个候选；失败原因只挂在 `data.temporaryReferenceError`，**不打日志**——真机日志里因此只见 `stateful_axis_no_y_reference`。读码推演悬空 y 柱那几处：候选 `605,71,-4` 非保留、下方整列无图纸格、8 格内有地面或侧面墙可起柱，理论上能立——**与真机结果矛盾，原因 UNKNOWN**，属放置层，本轮按任务书不碰
