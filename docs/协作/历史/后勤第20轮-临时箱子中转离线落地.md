## 白话摘要

上一次盖房子（建造 25）卡在一个「功能之间打架」的空档上：她背包里还塞着上一段工程剩的红石、活塞、漏斗，清完地皮捡起草皮就再也放不下东西了。管保命的那套按设计把盖房子按停、改让她去存东西，可她站的是荒地，方圆三十二格一只箱子都没有——最近的那只在一百二十格开外。于是她每半分钟重试一次、次次找不到，房子永远起不来，上一轮是人用传送把她送到箱子边才解开的。

按您选的 C，这一轮把根治做了。现在她走到这一步会先看看能不能自己解决：**身上有箱子就在脚边放一只，没有但木板够就先合成一只**，放下的箱子当场记成「她自己的箱子」（以后再要存东西就直接找得到它），然后把这一栋用不上的旧料存进去、接着盖房子。选位置有三条规矩：伸手够得着、脚下踩得住、**绝不放进图纸占的范围里**——图纸上标着「这里要留空」的格子（比如上楼的楼梯井）也算图纸范围，往里塞一只箱子等于把上楼的路堵死。三条有一条不满足，或者她既没箱子也没木板，就原样退回老做法，行为跟以前一模一样。

有一个取舍要说明：**放下的箱子不收走**，留在工地当物资箱。收走等于把东西又一件件塞回她背包，白忙一趟。

## 交接

### 给建造线（建造 27 真机验时照这个来）

1. **怎么造出这个场景**：让她背包塞满**不是本图纸材料**的东西（红石/活塞/漏斗/观察者这类上一段工程的旧料，塞到只剩 0–1 个空位），在**方圆 32 格没有任何箱子**的荒地上下建造命令。清地皮捡到草皮那一下就会触发。
2. **怎么判断走的是新路径**（按时间顺序找这几行）：
   - `[WORKSITE_UNLOAD_NO_CHEST] radius=32 keepItems=<N> action=deploy_temporary_chest` ← 生存系统派出了带授权的这一趟
   - `[TEMP_CHEST_SPOT] pos=x,y,z tried=<n> rejected=…` ← 选中的位置，以及前面几格为什么被否
   - `[TEMP_CHEST_CRAFTED] planks=<木板名> cost=8` ← 只有需要现合成时才有
   - `[TEMP_CHEST_PLACED] pos=x,y,z source=inventory|crafted:<木板名> registered=true keepItems=<N>` ← 放下并登记成功
   - `[TEMP_CHEST_STORED] pos=x,y,z source=… kinds=<N> items=[…]` ← 真存进去了什么、几件
   - `[TEMP_CHEST_LOCKS] types=movement,inventory restored=true reason=ok` ← 借完 `placeBlock` 锁还回来了。**这一行如果 `restored=false`，兜底会主动放弃，属设计内**
3. **没走新路径时会看到什么**（这几条都是「按设计回落」，不是 bug）：
   - `[TEMP_CHEST_SKIPPED] … reason=no_chest_and_no_planks` 她既没箱子也没 8 块同种木板
   - `[TEMP_CHEST_SKIPPED] … reason=place_failed:<原因>` / `reason=place_unverified` 放置本身失败
   - `[TEMP_CHEST_SPOT_NONE] origin=… bounds=… rejected=…` 12 个候选位全被否（每一格都带原因）
   - 完全没有 `[TEMP_CHEST_*]`：要么 32 格内本来就有箱子（老路径，正常），要么根本没进 `INVENTORY_FULL`
