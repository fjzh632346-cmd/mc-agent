## 修缮线专属服务器（第 1 轮建成）

服务器目录在仓库外，`scripts/mc-server.ps1` 不需要改动——它本来就认 `MC_SERVER_DIR`，
端口从该目录下的 `server.properties` 读，所以建造线默认跑 25565 的用法完全不受影响。

```powershell
$env:MC_SERVER_DIR = 'D:\code\MC-server-fix'   # 起停服务器时必带，否则会操作到建造线那台
scripts\mc-server.ps1 start | stop | status

# 起 bot 必须带这两个环境变量
$env:MC_PORT = '25566'
$env:MC_WORLD_ID = 'fixing-A:修缮世界'
```

- 停服务器走 RCON 优雅停（`stop`），**不要杀进程**
- 停 bot 只杀自己那个 pid，**绝不能用 `taskkill /F /IM node.exe`**——会连建造线的 bot 一起杀
- ONLINE-GATE：指定 `MC_PORT` 时「找到 MC 服务器」的替代信号是「[端口] 使用 .env 指定端口: 25566」；
  第四条 `[DEBUG_STATUS]` 要靠游戏内 `debug_status` 聊天指令触发，纯连线冒烟看不到属正常
