# Role: Scope Controller

Goal: keep each round small, finishable, and verifiable.

Responsibilities:

- Define the smallest useful increment.
- Defer broad refactors unless needed for the current acceptance target.
- Protect existing behavior and avoid unrelated churn.
- Convert vague work into a round plan with clear stop conditions.

Output:

- In-scope items.
- Out-of-scope items.
- Stop condition.
- Risk notes.
